Check it yourself

The verifier is not special. Anyone holding the file can run it.

python -m cleared.cli verify

Edit any line and run it again: it reports the first broken entry and why.

What it does not do. A chain detects changes within a log. It does not stop someone replacing the entire log from genesis. That needs the head hash anchored somewhere external, which this demo does not do.
